# קראו את התווית — ניתוח מצרכים לסוכרת

אתר להעלאת/צילום תמונה של טבלת ערכים תזונתיים, חילוץ אנרגיה ופחמימות ל-100 גרם (ועוד),
המלצה מותאמת לרמת סוכרת (כולל סוכרת הריון בשילוב), וצ'אט שמוגבל להקשר של המוצר בלבד.

כל הקריאות ל-AI עוברות דרך שירות **Google Gemini** (מודל `gemini-3.5-flash`) במסלול החינמי שלו —
ללא עלות, ללא צורך בכרטיס אשראי. מפתח ה-API נשמר אך ורק בצד השרת (Vercel Serverless Functions),
ואף פעם לא נחשף בדפדפן.

## מבנה הפרויקט

```
index.html          ← הדף עצמו (סטטי, כל ה-UI/UX/CSS)
api/analyze.js       ← מקבל תמונה, מחזיר חיתוך תזונתי (JSON) — שרשרת מודלי Gemini
api/recommend.js     ← מקבל נתוני תזונה + פרופיל, מחזיר המלצה — שרשרת Gemini + גיבוי Groq
api/chat.js          ← צ'אט מוגבל להקשר, שומר היסטוריית שיחה — שרשרת Gemini + גיבוי Groq
lib/gemini.js         ← לוגיקת השרשור: מנסה כמה מודלי Gemini לפי סדר עד שאחד מצליח
lib/groq.js           ← קריאה ל-Groq (ספק חינמי נפרד, גיבוי אחרון לשלבי הטקסט)
```

## איך מנוצלת המכסה החינמית ביעילות (חשוב!)

הגבלות הקצב של Gemini (RPM/RPD) נספרות **לפי מודל**, לא לפי חשבון. לכן במקום להסתמך על מודל
בודד, האתר מנסה שרשרת מודלים — אם הראשון עמוס (שגיאת 429), עוברים אוטומטית לבא בתור,
**עם אותו מפתח API בדיוק**, בלי צורך בהרשמה נוספת:

- **`api/analyze.js`** (ניתוח תמונה — הצריכה הכבדה ביותר): `gemini-3.5-flash` → `gemini-2.5-flash` →
  `gemini-3.5-flash-lite`. **כל מכסת ה-Gemini שמורה לשלב הזה בלבד.**
- **`api/recommend.js`** (טקסט בלבד): `gemini-3.5-flash-lite` → `gemma-3-27b-it` → **Groq** (אם הוגדר `GROQ_API_KEY`)
- **`api/chat.js`** (טקסט בלבד, שלב 4): **אינו נוגע ב-Gemini כלל** — מתחיל ישירות ב-**OpenRouter**
  (אם הוגדר `OPENROUTER_API_KEY`) ← **Groq** (אם הוגדר `GROQ_API_KEY`). כך כל מכסת ה-Gemini החינמית
  נשארת פנויה לניתוח התמונה, שהוא השלב היקר והחשוב באמת. הצ'אט חייב לפחות אחד מבין שני המפתחות
  האלה כדי לעבוד — בלעדיהם הוא יחזיר שגיאת הגדרה ברורה במקום להיכשל בשקט.

הצ'אט (שלב 4) לא צריך את איכות Gemini — זו שיחה קלה על נתונים שכבר חולצו, אז שני ספקים חינמיים
עצמאיים (OpenRouter ו-Groq) מספיקים לו לגמרי, ומשאירים את Gemini פנוי לחלוטין לניתוח התמונות.

חשוב לדעת: בדקתי את זה במפורש — ל-OpenAI (ChatGPT), Anthropic (Claude) ול-xAI (Grok) **אין**
מסלול API חינמי מתמשך נכון לאמצע 2026 (רק קרדיט התנסות חד-פעמי שפוקע, או כלום). לכן שרשור
אליהם לא באמת "חינם". **Groq** (לא להתבלבל עם Grok של xAI) ו-**OpenRouter** כן מציעים מסלול חינמי
אמיתי ומתמשך על מודלים פתוחים, אך ללא תמיכה אמינה בראיית תמונות — לכן שניהם משמשים כאן רק כגיבוי
לשלבי הטקסט (המלצה + צ'אט), לא לניתוח התמונה עצמו.

### הפעלת שכבות הגיבוי (Groq ו/או OpenRouter — לפחות אחד מהם נדרש כדי שהצ'אט יעבוד בכלל)

חשוב: מאחר שהצ'אט (`api/chat.js`) לא נוגע ב-Gemini כלל, צריך להגדיר לפחות אחד מהמפתחות הבאים
כדי שהצ'אט יפעל. `api/recommend.js` לעומת זאת עדיין עובד גם בלי אף אחד מהם (הוא נופל חזרה ל-Gemini).

**Groq** (המלצה + צ'אט):
1. הרשמה חינמית ב-[console.groq.com](https://console.groq.com) (בלי כרטיס אשראי) ויצירת מפתח.
2. ב-Vercel: Settings → Environment Variables → הוסיפו `GROQ_API_KEY` עם המפתח שקיבלתם.

**OpenRouter** (צ'אט בלבד):
1. הרשמה חינמית ב-[openrouter.ai/keys](https://openrouter.ai/keys) (בלי כרטיס אשראי) ויצירת מפתח.
2. ב-Vercel: Settings → Environment Variables → הוסיפו `OPENROUTER_API_KEY` עם המפתח שקיבלתם.

לאחר הוספת מפתחות — Redeploy. אם כל מודלי Gemini עמוסים, ה-API יעבור אוטומטית לשכבה הבאה בשרשרת
(ניתוח התמונה עצמו ימשיך להסתמך על שרשרת Gemini בלבד).

## פריסה ל-Vercel (שלב-אחר-שלב)

1. **קבלו מפתח Gemini חינמי** — כנסו ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey),
   התחברו עם חשבון Google, ולחצו "Create API key". אין צורך בכרטיס אשראי במסלול החינמי.

2. **העלו את התיקייה הזו ל-GitHub** (repo חדש), או גררו אותה ישירות ל-Vercel דרך
   [vercel.com/new](https://vercel.com/new) (אפשר גם "Deploy" ישיר מתיקייה מקומית עם ה-CLI, ראו למטה).

3. **בפרויקט ב-Vercel:** Settings → Environment Variables → הוסיפו:
   - Key: `GEMINI_API_KEY`
   - Value: המפתח שקיבלתם בשלב 1
   - Environment: Production (וגם Preview/Development אם תרצו לבדוק לפני שחרור)
   - `GROQ_API_KEY` ו/או `OPENROUTER_API_KEY` — **חובה לפחות אחד מהם כדי שהצ'אט (שלב 4) יעבוד** —
     ראו סעיף הגיבוי למעלה

4. לחצו **Deploy**. Vercel יזהה אוטומטית את `index.html` הסטטי ואת התיקייה `api/` כ-Serverless Functions —
   אין צורך בהגדרות build נוספות.

### פריסה מהירה מהטרמינל (חלופה)

```bash
npm i -g vercel
cd nutrition-app
vercel                     # פריסת preview
vercel env add GEMINI_API_KEY production
vercel env add GROQ_API_KEY production        # אופציונלי
vercel env add OPENROUTER_API_KEY production  # אופציונלי
vercel --prod              # פריסה לפרודקשן
```

## הרצה מקומית

```bash
npm i -g vercel
vercel dev
```
זה יריץ גם את `index.html` וגם את פונקציות ה-`api/` על `localhost`, בדיוק כמו בפרודקשן.
ודאו שיש קובץ `.env` מקומי עם `GEMINI_API_KEY` (ראו `.env.example`).

## על המסלול החינמי של Gemini

נכון לזמן כתיבת האתר, מודלי ה-Flash של Gemini נעים סביב 15 בקשות בדקה ו-1,500 בקשות ביום
במסלול החינמי — נדיב מאוד לשימוש אישי/ביתי, במיוחד עכשיו שהאתר משתמש בכמה מודלים נפרדים
במקביל (ראו סעיף המכסה למעלה). Google מוציאה משימוש (deprecate) מודלים ישנים בקצב מהיר יחסית —
אם בעתיד תקבלו שגיאה כמו "model is no longer available", בדקו את הרשימה העדכנית ב-
[ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models) ועדכנו את
מערך `MODEL_CHAIN` בקבצים הרלוונטיים תחת `api/` לשמות המודלים היציבים החדשים.

אם תרצו לשדרג בעתיד לנפח שימוש גבוה יותר, אפשר לעבור למסלול בתשלום של Gemini בלי לשנות שורת קוד אחת — רק המפתח וההגבלות משתנים.
